# Автоматизация тестирования Saby и Tensor

Этот проект содержит автотесты для проверки функционала сайтов Saby и Тензор. Реализован с использованием Python, Selenium и Pytest.

## Описание тестов
1. **Навигация и контент**:
   - Переход на сайт Тензор.
   - Проверка блока "Сила в людях".
   - Контроль одинакового размера изображений в разделе "Работаем".
   
2. **Региональность**:
   - Смена региона на Камчатку.
   - Проверка изменения URL, заголовка страницы и списка партнеров.
   
3. **Скачивание файла**:
   - Проверка перехода в раздел "Скачать".
   - Выбор плагина для 1С.
   - Сверка размера скачанного файла с указанным на сайте.

## Структура проекта

- `pages/` — объектная модель страниц (Page Object Model).
- `tests/` — сценарии тестов.
- `utils/` — вспомогательные инструменты (например, работа с файлами).
- `conftest.py` — настройки драйвера и фикстуры.
- `pytest.ini` — настройки запуска и логирования.
